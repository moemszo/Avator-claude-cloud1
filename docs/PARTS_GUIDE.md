# パーツ画像の作り方（ChatGPT 画像生成向け）

このアバターは **「1枚の基本画像」＋「目・口・表情だけを変えた差分画像」** で動きます。
差分画像は、アプリが **楕円の範囲（目・口・顔まわり）だけを切り抜いて** 基本画像に重ねます。
そのため、差分画像の髪や体が少しくらい崩れていても問題ありません。
**目・口のまわりが基本画像とほぼ同じ位置にあること**が大事です。

顔の向きや傾き・髪の揺れは、アプリが基本画像を変形させて作ります。横顔や後ろ姿の画像は要りません。

---

## 1. 作る画像の一覧

置き場所: `avatar/parts/`（同じ名前のファイルを上書き）

| ファイル名 | 必須 | 内容 | 使われ方 |
|---|:---:|---|---|
| `base.png` | ◎ | 基本画像。正面・目を開けて・**口を閉じた**普通の顔 | すべての土台 |
| `eyes_closed.png` | ◎ | 両目を閉じた顔 | まばたき |
| `eyes_half.png` | ○ | 半目 | まばたき途中・細目 |
| `exp_smile.png` | ○ | 笑顔（^^ の目） | キー `2` |
| `exp_shy.png` | ○ | 照れ（赤面） | キー `3` |
| `exp_surprised.png` | ○ | 驚き | キー `4` |

- ◎ の 2 枚があれば動きます。
- **口の画像は要りません。** 口はアプリがアニメ調で描き、開き・横に引く・すぼめる・口角を連続的に動かします。
  表情画像の口は下ごしらえで消して、同じように描き直します。
- 差分画像では変える所を 1 つに絞り（目の画像なら目だけ）、それ以外は **基本画像と同じ** にしてください。

## 2. すべての画像に共通のルール

| 項目 | 指定 |
|---|---|
| サイズ | **1024 × 1536 px（縦長 2:3）**。全部同じサイズにする |
| 背景 | **透過 PNG**（ChatGPT に「背景を透明に」と指示） |
| 構図 | 頭のてっぺん（アホ毛）から腰（Tシャツの裾が少し見える所）まで。**胸は必ず全部入れる** |
| 位置 | キャラは左右中央。頭の上に 5〜8% ほど余白を空ける（頭を動かす余裕のため） |
| 向き | 真正面。顔もまっすぐ正面、視線はカメラ（見る人）に向ける |
| ポーズ | 腕は自然に下ろす（手は画面外で OK）。髪が目に深くかからないようにする |
| 絵柄 | 設定資料と同じアニメ塗り・同じ線の太さ・同じ色 |

> 💡 **一番大事なのは、差分画像を「新しく描かせる」のではなく「`base.png` を編集させる」ことです。**
> 毎回 `base.png` を添付して、「〇〇だけ変えて、ほかは全く同じに」と頼んでください。位置ずれがぐっと減ります。

## 3. 手順

### ステップ 1: 基本画像 `base.png` を作る

設定資料の画像を **添付して**、次のように頼みます。

```
添付したキャラクター設定資料の女性キャラクターを、VTuber 用の立ち絵として描いてください。

【絵柄】設定資料と全く同じアニメ調の絵柄・塗り・線・配色にしてください。
【キャラクター】
- ピンク色でふわっとした外ハネのショートボブ、頭頂部にアホ毛
- 向かって右側（キャラの左側）の顔横から、長めの髪の房が肩の前に垂れている
- 赤みがかったピンク色の瞳、頬にうっすら赤み
- 緑色の半袖 V ネック T シャツ（胸元が開いたデザイン）、大きな胸
- 濃い青のスキニージーンズ（ウエスト部分だけ見える）
【ポーズ・表情】
- 真正面を向いて立ち、顔も体もまっすぐ正面。視線は見る人に向ける
- 両腕は体の横に自然に下ろす
- 表情は穏やかな普通の顔。目はぱっちり開け、**口は閉じて**軽く微笑む
【構図】
- 縦長 1024×1536、キャラを左右中央に配置
- 頭のてっぺん（アホ毛）から腰まで（T シャツの裾とジーンズのウエストが少し見える）。胸は全部入れる
- 頭の上に少し余白を空ける
【背景】透明（透過 PNG）
```

**チェック**
- 口がちゃんと閉じているか（設定資料は口を開けた笑顔なので注意）
- 目が髪で隠れすぎていないか
- 背景が透明か

気に入るまで作り直してください。以降の画像はすべて、この 1 枚が土台になります。

### ステップ 2: 差分画像を作る（`base.png` を毎回添付）

共通の頼み方（`{変更内容}` の所だけ入れ替えます）:

```
添付した画像を編集してください。
{変更内容}
それ以外の部分（髪型・髪の房・輪郭・眉・体・服・ポーズ・構図・キャラの位置と大きさ・色・線の太さ）は
一切変えず、元の画像と完全に同じにしてください。画像サイズ 1024×1536、背景は透明のままにしてください。
```

| ファイル名 | `{変更内容}` に入れる文 |
|---|---|
| `eyes_closed.png` | 両目だけを完全に閉じた状態にしてください。まつ毛が下向きのやわらかい弧になる、自然なまばたきの閉じ目です。眉は動かさないでください。 |
| `eyes_half.png` | 両目だけを半分閉じた半目にしてください。上まぶたが瞳の上半分を覆う程度です。眉は動かさないでください。 |
| `exp_smile.png` | 表情を満面の笑顔にしてください。目は閉じた「^^」形の笑い目、頬を赤らめ、口は開けて笑います。変えるのは目・眉・頬・口だけです。 |
| `exp_shy.png` | 表情を照れ顔にしてください。頬から鼻の上を強めに赤らめ、眉を少し下げた困り眉にします。目は開いたまま少し潤ませ、口は閉じて小さくはにかみます。変えるのは目・眉・頬・口だけです。 |
| `exp_surprised.png` | 表情を驚き顔にしてください。目を大きく見開き、眉を上げ、口は小さな「お」の形に開けます。変えるのは目・眉・口だけです。 |

**チェック**
- 基本画像と並べて切り替えたとき、目・口の位置がずれていないか（少しなら後でアプリで補正できます）
- キャラの大きさが変わっていないか（大きさが変わると補正できないので、作り直してください）

### ステップ 3: 髪のずれを取り除く（自動）

画像生成 AI は、「目だけ変えて」と頼んでも髪の毛の線を少しずつ描き直します。
そのままだと、まばたきや表情を切り替えるたびに前髪がピクッと動いて不自然になります。
そこで、次の下ごしらえスクリプトで **髪を基本画像とまったく同じにそろえます**。

1. 作った画像を `avatar/source/` にパーツ名で置きます（例: `eyes_closed.png`）。
2. 次を実行します（Python 3 と pillow・numpy が必要です）。
   ```
   pip install pillow numpy
   python scripts/prepare_parts.py
   ```
3. `avatar/parts/` に、下ごしらえ済みの画像が書き出されます。

スクリプトがやっていること:
- 基本画像との数 px の位置ずれを、自動で見つけて合わせます。
- 髪の毛の色をした所は、基本画像の髪で上書きします。
- 目の中・口・（表情画像の）眉は保護して、差分画像のまま残します。保護範囲は `avatar.json` の `cleanup` で変えられます。
- 基本画像と表情画像から口を消した `nomouth_*.png` を作ります（消す範囲は `cleanup.mouthErase`）。
- 目線用に、基本画像から黒目を切り出します（`iris.png`・黒目を白目で埋めた `eye_socket.png`・黒目が見えてよい範囲 `eye_mask.png`）。
  黒目の位置と大きさは `cleanup.irises` で指定します。基本画像を作り直したら、ここも合わせてください。

### ステップ 4: アプリで範囲と位置を合わせる

1. `avatar/parts/` の画像が新しくなっていることを確認します。
2. `npm start` でアプリを開き、`E` キーで **パーツ調整モード** にします。
3. 楕円をドラッグして、あなたの画像に合わせます（中心の点で移動、右下の四角で大きさを変えます）。

   | 楕円 | 合わせ方 |
   |---|---|
   | 青（目 2 つ） | 眉の下から下まつ毛の少し下まで。まぶたが動く範囲がすっぽり入る大きさ |
   | 赤（口を描き直す範囲） | 一番大きく開けた口がはみ出さない大きさ |
   | 赤い十字（口の位置） | 閉じた口の線の真ん中に合わせる |
   | 紫（表情の範囲） | 眉・目・頬・口をまとめて囲む |
   | 緑（頭） | 髪全体を囲む。この中が顔の向きに合わせて動く |
   | オレンジの横線（首の付け根） | 首と肩の境目あたり。ここより下は頭と一緒には動かない |

4. 「重ねて確認する画像」で差分画像を選ぶと、その画像が半透明で重なります。
   ずれていたら `←` `→` `↑` `↓`（または矢印キー。Shift で 10px ずつ）で合わせます。
5. 「ふちのぼかし」で、切り抜きの境目が目立たないように調整します。
6. 「保存」を押すと、`avatar/avatar.json` に書き込まれます。

## 4. よくある困りごと

| 症状 | 対処 |
|---|---|
| まばたきすると目の周りの色が少し変わる | 差分画像の色がずれています。「ふちのぼかし」を大きくするか、「色味も元画像と完全に同じに」と頼んで作り直す |
| 差分画像のキャラが大きさごと変わってしまう | 「キャラの位置と大きさを 1 ピクセルも変えない」と強めに指示して作り直す |
| 背景が透明にならない | 「背景を透明（透過 PNG）にして」と再度頼む。ダメなら背景除去ツールで透過する（差分画像は透過でなくても動きます。透過が必須なのは `base.png` だけ） |
| 顔を大きく横に向けると絵が伸びる | 1 枚絵を変形させているための限界です。「感度」の「顔の左右」を下げるか、`avatar.json` の `motion.yawPx` を小さくする |
