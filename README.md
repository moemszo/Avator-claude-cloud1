# VTuber アバター（顔トラッキング・正面バストアップ）

Webカメラで顔を読み取り、2D のアバターを動かすブラウザアプリです。

- **目**: まばたき、ウインク（左右の目を別々に）、**目線**（黒目が上下左右に動く）
- **口**: 開け閉めと、口の形（あ・い・う・え・お）
- **顔の向き**: 左右を向く、上下にうなずく、首をかしげる。首と胴体は一体で動き、向いた方向・かしげた方向へ上半身ごと傾きます
- 髪は頭より少し遅れて揺れ、体は呼吸するように少しだけ動きます
- 手は動きません。画面には上半身（胸を含む）が映ります。向きは正面のみです

顔の解析には Google MediaPipe を使います。**ブラウザの中だけで動くので、カメラ映像は外部に送信されません。**

> 📝 `avatar/source/` が ChatGPT で作った元画像です。`avatar/parts/` は、そこから下ごしらえ（髪のずれ取り）をした画像です。
> 今あるのは、基本・閉じ目・笑顔・照れ・驚き・「え」の口です。「あ」の口は笑顔、「お」の口は驚き顔から流用しています。
> 足りない画像（半目・「い/う」の口）の作り方と、下ごしらえの手順は **[docs/PARTS_GUIDE.md](docs/PARTS_GUIDE.md)** を見てください。

## 起動方法

Node.js 18 以上が必要です。

```bash
npm install     # MediaPipe と顔モデル（約 4MB）を取得
npm start       # → 画面に表示されたアドレス（通常 http://127.0.0.1:8765）
```

Chrome か Edge で、`npm start` の後に表示されるアドレス（通常 http://127.0.0.1:8765）を開き、「カメラ開始」を押してください。
ほかのアプリ（llama.cpp など）がその番号を使っている場合は、自動で次の番号（8766…）になります。
1. カメラの使用を許可します。
2. 正面を向いて **`C` キー**（または「正面を基準にする」）を押します。これで、今の顔が基準（正面・通常）になります。

> `index.html` をダブルクリックで直接開くと動きません（カメラやモジュールの制限のため）。必ず `npm start` 経由で開いてください。

## キー操作

| キー | 動作 |
|---|---|
| `1` `2` `3` `4` | 表情: 通常 / 笑顔 / 照れ / 驚き |
| `0` | 通常の表情に戻す |
| `C` | 今の顔を正面の基準にする |
| `B` | 背景を切り替え（淡いピンク → グリーンバック → ブルーバック → 透明 → 白） |
| `D` | カメラ映像と顔の点を表示（デバッグ） |
| `H` | 右の操作パネルを隠す／出す |
| `E` | パーツ調整モード（パーツの範囲と位置を合わせる） |

表情キーの動き:
- 笑顔は目を閉じた表情なので、この表情の間はまばたきを反映しません。
- 口パクはどの表情でも有効です。

## パネルの設定

- **感度**: 顔の左右・上下・かしげ・口の開き・目の閉じやすさ・目線の動き・なめらかさ
- **鏡のように動かす**: オンのとき、あなたが右を向くとアバターは画面の右を向きます（鏡と同じ）
- **顔が映っていない時に自動でまばたき**: カメラを止めているときも、ゆっくり揺れてまばたきします

設定はこのブラウザに保存され、次回もそのまま使えます。

## 自分のパーツ画像に差し替える

1. [docs/PARTS_GUIDE.md](docs/PARTS_GUIDE.md) の手順で画像を作り、`avatar/source/` に置きます。
   `python scripts/prepare_parts.py` を実行して、髪のずれを取った画像を `avatar/parts/` に書き出します。
2. `E` キーでパーツ調整モードにして、目・口・顔・頭の楕円を画像に合わせ、「保存」を押します。

## 仕組み

```
Webカメラ ─→ MediaPipe Face Landmarker（顔の 478 点 + 表情の値）
            └→ js/tracker.js   目の開き・口の形・顔の向きを数値にする
                 └→ js/main.js     数値 → 目の状態 / 口の形 / 頭の角度（なめらか処理・髪の遅れ）
                      ├→ js/avatar.js   base.png に目・口・表情の差分画像を楕円範囲で重ねる
                      └→ js/renderer.js 合成した絵を WebGL の格子に貼り、頭・髪・体を変形して描画
```

| ファイル | 役割 |
|---|---|
| `avatar/avatar.json` | 画像ファイル名、楕円の範囲、動きの大きさ（`motion`）、表情キーの割り当て |
| `js/editor.js` | パーツ調整モード |
| `scripts/prepare_parts.py` | 差分画像の下ごしらえ（位置合わせ、髪を基本画像にそろえる、目線用の黒目の切り出し） |
| `server.js` | ローカル用の簡易サーバー（パーツ調整の保存もここで受けます） |

`avatar.json` の `motion` の値:

| 値 | 内容 |
|---|---|
| `yawPx` / `pitchPx` | 顔のパーツが左右／上下にずれる大きさ（px、立体感） |
| `leanPerYaw` | 顔を左右に向けたときに上半身が傾く量（ラジアン） |
| `leanRollShare` | 首のかしげのうち、上半身ごとの傾きで表す割合（残りは頭だけ） |
| `maxLean` | 上半身の傾きの上限（ラジアン） |
| `bodyShiftPx` | 向いた方向へ体が横に動く量 |
| `rollScale` | 首のかしげの強さ |
| `gazePxX` / `gazePxY` | 黒目が動く最大の幅（px） |
| `hairLag` | 髪の遅れ具合 |
| `breath` | 呼吸の大きさ |

## 困ったとき

| 症状 | 対処 |
|---|---|
| 開くと別のアプリ（Llama など）が表示される | ほかのアプリと番号が重なっています。`npm start` の画面に出たアドレスを開く |
| 「カメラの使用が許可されませんでした」 | アドレスバー左のアイコンからカメラを許可して、再読み込みする |
| 顔が動くのと逆向きにアバターが動く | 「鏡のように動かす」を切り替える |
| 目が閉じっぱなし／閉じない | 正面を向いて `C` を押す。それでもダメなら「目の閉じやすさ」を調整する |
| 口が開きっぱなし／開かない | 口を閉じて `C` を押す。「口の開き」の感度を調整する |
